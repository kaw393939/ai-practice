# Start here

Practice one small change with AI: **add a helpful sentence below the Note box** in the example app. You do not need to build the rest of the link library.

## Before you begin

Use **ChatGPT desktop** to discuss the task, **Codex** to work on the local project, and **VS Code** to read and edit files. Use your class terminal for Git commands and running the app. You also need a GitHub account.

**First:** complete [Setup](./setup#ready-to-begin) with your instructor before the exercise. If your workspace is ready, go directly to [Your first change](./practice). No OpenAI API key is needed.

## Follow one cycle

1. **Describe:** read the supplied [practice spec](./specs/practice).
2. **Discuss:** ask AI for a short plan; resolve anything unclear before editing.
3. **Record:** create the supplied issue in your own repository.
4. **Build:** ask AI to make only that change on a branch, a separate version of your work.
5. **Check:** try the result and give specific feedback if it differs from the spec.
6. **Keep:** review the changed files in a pull request, then merge into your own main version.

Follow [Your first change](./practice) for the exact steps and prompts. In class, start from a working workspace and watch the instructor demonstrate the cycle. Your job is to explain the change, review the plan, try the result, and give useful feedback.

The instructor's [completed LINK-001 example](./example) shows work already done. Your practice task is **PRACTICE-001**, in your own repository created from the template. Your issue and pull request go there too.
